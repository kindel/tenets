# tenets

A copy-paste prompt that helps an agent write and pressure-test a set of tenets.

Tenets are a few carefully articulated guiding principles for any endeavor. They align a group on a vision, simplify decision-making, and distinguish welcome behavior from unwelcome behavior. They are tiebreakers when the call cannot be settled with data. Principle and tenet are the same word.

The teaching is in [Tenets](https://blog.kindel.com/2020/02/10/tenets/) and [Debate Tenets](https://blog.kindel.com/2019/05/23/debate-tenets/). This repo is the editor: `prompt.md`.

There is no app. Copy the prompt into an agent, then describe the endeavor or paste a draft set.

## Use

1. Copy [`prompt.md`](prompt.md).
2. Paste it into any agent (ChatGPT, Claude, Cursor, Grok, whatever you already use).
3. Tell it the endeavor, or paste the current list.

If the list is actually a pile of slogans, a good run will say so and fix it. If the input is too thin to take a stand, it should ask before inventing a business.

## What you should get back

A working set you can paste at the top of a narrative, each tenet marked Foundational or Aspirational, a short editor note on the trade-off, a review against the tenets for tenets, and a few debate questions the room should actually fight about.

The set ends with "unless you know better ones." That is not decoration. Tenets evolve.

## Tenets for tenets

The prompt scores every draft against these (from the Tenets post):

1. Obsess over customers.
2. Be memorable.
3. Be endeavor-specific, or more specific than that.
4. Counsel (take a stand; guide a trade-off).
5. One main idea.
6. Find a minimal cover.
7. Orient for the long term.
8. A tenet is not something to be done later (present tense).
9. Distinguish rather than elevate.

The most common miss is a line that would fit any team and says nothing. "Our team builds scalable systems" is the canonical example of a wasted tenet.
